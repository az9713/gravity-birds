🎮 Gravity Birds - Web Version

How to Run

This HTML5 export requires a local web server due to browser security restrictions.

Quick Start (Python 3):

cd export/web
python3 -m http.server 8000

Then open http://localhost:8000 in your browser.

Alternative Methods:

  • PHP: php -S localhost:8000
  • Node.js: npx http-server -p 8000
  • VS Code: Install "Live Server" extension and click "Go Live"

Game Controls:

  • Arrow Keys or WASD: Move creature
  • Z: Undo
  • R: Restart
  • On-screen buttons: Undo / Restart / Menu

Objective:

Collect all fruit (orange circles) to unlock the exit (green square), then reach it with your creature's head!

Note: The actual game is in index.html. This file provides setup instructions.

Open the Godot project in Godot Editor to play directly, or follow the instructions above to play the web version.
